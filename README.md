# Annika Lee Portfolio — V15 Self-Contained Upload

This build is intentionally self-contained for GitHub Pages.

## Why this version fixes the images

All portfolio images are embedded directly inside each HTML page. The CSS and JavaScript are embedded too. There is no `assets/` folder and no `styles.css` or `script.js` dependency in the upload build, so image paths cannot break if folders are missed during a GitHub upload.

## Upload these files to the ROOT of your GitHub repository

- `index.html`
- `work.html`
- `azilis.html`
- `tuff.html`
- `padel.html`
- `please.html`
- `shed.html`
- `bec.html`
- `luma.html`
- `social-media.html`
- `events.html`
- `404.html`
- `resume.pdf`

You can upload `README.md` too, but it is not required for the website.

## Important

Replace the existing website files with these V15 files. Do not upload the ZIP itself into the repository. Unzip it first, then upload the files inside.
